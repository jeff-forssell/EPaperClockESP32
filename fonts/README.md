# Font files and upstream licensing

The font headers in this folder are bitmap fonts used by the display code.
These files are not original project code; they were derived from upstream
font projects and distributed with the Adafruit GFX / FreeFont ecosystem.

At minimum, keep the upstream attribution and license text with the font files,
and do not remove the original license information when redistributing them.

The current font files in this repository are based on the FreeMono / FreeSans
families and should be treated as open-source font data, not as handwritten code
from this repository.

Please check the exact upstream project for the final legal wording if you plan
to redistribute or publish the fonts in other contexts.
